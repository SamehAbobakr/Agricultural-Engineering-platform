## نظرة عامة

كان طلاب الكلية يفتقرون إلى مكان واحد يجمع المحاضرات والملفات ومتابعة التقدم والمصادر الأكاديمية. تجمع هذه المنصة كل ذلك في واجهة سريعة ومتوافقة مع الموبايل ومن اليمين لليسار، وتمنح المسؤولين لوحة إدارة مدمجة لإدارة كل المحتوى دون لمس الكود.

صُممت المنصة لتكون خفيفة عمدًا: HTML وCSS وJavaScript عادي **بدون أدوات بناء**، وتُنشر كملفات ثابتة على GitHub Pages. البيانات والمصادقة على **Supabase** (PostgreSQL مع Row Level Security)، والملفات الكبيرة تُخدَّم من **Cloudflare R2**.

| المجال | الوظيفة |

| **لوحة الطالب** | أهداف وتقدم في المواد وملاحظات، مرتبطة بحساب الطالب ومحمية بسياسات RLS. |
| **دليل هيئة التدريس** | ملفات تعريفية قابلة للبحث والتصفية. |
| **مجتمع الطلاب والخريجين** | دليل أعضاء مع عارض صور. |
| **مشاريع التخرج** | أرشيف بالبحث والفلاتر والترتيب، وصفحة تفاصيل لكل مشروع. |
| **لوحة الإدارة** | إدارة كاملة للمواد والملفات والغرف والمهام والأسئلة وهيئة التدريس والمجتمع ومشاريع التخرج والمسؤولين، ومقصورة على المسؤولين ببريد مؤكَّد. |
| **المصادقة** | بريد وكلمة مرور وGoogle، وتأكيد البريد، واستعادة كلمة المرور، والعودة الآمنة للصفحة بعد الدخول. |
| **المظهر وإمكانية الوصول** | وضع ليلي/نهاري بلا وميض، ودعم كامل لـ RTL، وخط Cairo، وتنقل بلوحة المفاتيح مع خصائص ARIA. |

## التنقل

يرتّب الهيدر الرئيسي ثماني صفحات في قائمتين منسدلتين على الكمبيوتر، وتصنيفين قابلين للطي داخل درج جانبي على الموبايل.

| المنصة والخدمات | المجتمع الأكاديمي |
|---|---|
| الرئيسية | أعضاء هيئة التدريس |
| لوحة الطالب | مجتمع الطلاب والخريجين |
| الأدوات | مشاريع التخرج |
| المسار التعليمي | تواصل معنا (واتساب) |

التصميم بأسلوب «الزجاج الفاخر»، ويعمل بالماوس واللمس ولوحة المفاتيح (Tab وEnter والأسهم وHome/End وEscape)، ويُغلق بالنقر خارجه، ويميّز الصفحة الحالية بوضوح.

## نقاط التميز الهندسي

- **الأمان مفروض داخل قاعدة البيانات.** المتصفح يحمل مفتاحًا عامًا فقط، والصلاحيات تحكمها Row Level Security. إكمال المهام والنقاط يُسجَّل حصرًا عبر الدالة `complete_task`، والهوية والنقاط تُستنتج من الجلسة وجدول `tasks` ولا يُوثق بها من العميل.
- **صلاحية المسؤول في PostgreSQL.** الدالة `is_admin()` تتحقق من بريد مؤكَّد مدرج في `admin_emails`، وتستخدمها لوحة الإدارة وسياسات RLS معًا.
- **مصدر واحد للحقيقة.** عميل Supabase واحد لكل صفحة، واشتراك مصادقة واحد، وملف إعدادات واحد، وتنفيذ واحد للهيدر مشترك بين الصفحات.
- **حماية من XSS.** كل نص من قاعدة البيانات يُهرَّب، وكل رابط مقيّد بـ http/https، ولا تُكتب بيانات داخل معالجات الأحداث المضمنة.
- **وحدات معزولة.** كل ميزة في مجلدها ببادئة CSS خاصة (`rm-` و`gp-` و`sw-`) لمنع تعارض التنسيقات.
- **لوحة إدارة مبنية كمحرك.** نواة CRUD عامة (راوتر ومستودع بيانات وقوالب HTML آمنة) وكل جدول وحدة صغيرة تصريحية.
- **بلا أدوات بناء للصيانة.** سهلة النسخ والمراجعة والنشر على أي استضافة ثابتة.
- **عناية تشغيلية.** مهمة GitHub Actions مجدولة تُبقي مشروع Supabase المجاني نشطًا، والمستودع يتضمن سكربتات اختبار للواجهة والمنطق في `tests-report/`.

## التشغيل

1. انسخ المستودع (Clone).
2. أنشئ مشروع Supabase والصق **Publishable Key** في `SUPABASE_KEY` داخل `js/config.js`.
3. من SQL Editor في Supabase نفّذ `database/admin/001_admin_setup.sql` ثم `002_add_admin.sql` (ضع بريدك فيه أولًا)، ثم ملفات الميزات التي تحتاجها (مثل `faculty_members.sql` و`community_members.sql` و`student_dashboard.sql` و`rooms_progress.sql` و`database/graduation/001_graduation_projects.sql`).
4. اضبط دخول Google وSMTP وروابط إعادة التوجيه حسب `docs/auth-setup.md`.
5. شغّل المجلد بأي خادم ثابت أو انشره عبر GitHub Pages.

لإعادة بناء تنسيقات لوحة الطالب بعد إضافة أصناف Tailwind:

</div>

```bash
cd student_dashboard
npm install
npm run build:css
```

## الأمان

- لا ترفع أبدًا مفتاح `service_role` أو أي سر آخر. المفاتيح العامة فقط مكانها هذا المستودع.
- كل جدول جديد يحتاج سياسات Row Level Security قبل إتاحته.
- المساعد الذكي يستخدم مفتاح مشروع مستقلًا عن قاعدة بيانات الموقع.
